# Supplier Hybrid Graph RAG

A beginner-friendly Hybrid Graph RAG application built with:

- React
- Vite
- Python
- FastAPI
- OpenAI embeddings
- FAISS
- NetworkX
- GPT-5-mini

## Architecture

PDF
→ Chunking
→ Embeddings
→ FAISS + Knowledge Graph
→ Hybrid Retrieval
→ GPT-5-mini
→ Answer + Sources

## Features

- Multi-document RAG
- Vector search
- Knowledge graph retrieval
- Semantic entity matching
- Document/page provenance
- Duplicate document prevention
- Persistent storage
